## Biomes O' Plenty

Supported leaves use the independent `betterfoliage_bop` asset namespace so
their names cannot conflict with BWG compatibility assets:

- `biomesoplenty:orange_maple_leaves` using
  `betterfoliage_bop:block/orange_maple_fluff`
- `biomesoplenty:red_maple_leaves` using
  `betterfoliage_bop:block/red_maple_fluff`
- `biomesoplenty:yellow_maple_leaves` using
  `betterfoliage_bop:block/yellow_maple_fluff`
- `biomesoplenty:cypress_leaves` using
  `betterfoliage_bop:block/cypress_fluff`
- `biomesoplenty:snowblossom_leaves` using
  `betterfoliage_bop:block/snowblossom_fluff`

The resource pack requires Better Foliage. Each compatibility section also
requires its corresponding content mod.
Place the directory or its ZIP archive in the Minecraft `resourcepacks`
directory and give it higher priority than other packs that replace supported
mod block models.
